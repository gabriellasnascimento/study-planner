# Project Proposal

## What are you building? Who is it for?
I am building a study planner web app for college students who want a simple way to organize assignments, deadlines, and study sessions. It is for students who need help managing their time and keeping all their school tasks in one place.

## Why? What problem does it solve?
I want to build this because students often have multiple assignments, exams, and responsibilities at the same time, which can make it hard to stay organized. This project solves that problem by giving users a clear and easy way to track their work, plan ahead, and avoid missing deadlines.

## MVP vs. Stretch Goals
### MVP
- Add study tasks and assignments
- Set due dates
- Mark tasks as completed
- View tasks by category such as upcoming, completed, or overdue
- Responsive design for desktop and mobile

### Stretch Goals
- Add a Pomodoro timer
- Add priority labels
- Save data with local storage
- Add a progress tracker
- Add a dark/light mode toggle

## What technologies do you plan to use?
I plan to use HTML, CSS, and JavaScript to build the app. I will use JavaScript for interactivity, DOM manipulation, and task management. I also plan to use local storage to save user tasks and GitHub Pages to deploy the final project.
